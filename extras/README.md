# Extras

[Español](README.es.md)

Things we had to build from scratch for the Retroid Pocket 6 because they did not exist anywhere else.
They are not part of the OS image (the image build never reads this folder). If you cloned this repo,
they are yours.

| Folder | What it is |
|---|---|
| [`rp6/screen-protector/`](rp6/screen-protector/) | Full-front screen protector cut template (DXF, SVG, PLT, printable PDF) measured from a 3D scan, plus the scripts that produce it |
| [`rp6/3d-scan/`](rp6/3d-scan/) | Where to get the 3D scan of the RP6 the template is measured from, with attribution |
